# Visual Language

## Purpose

The EllieAtWHL visual language is deliberately restrained.

It is designed to create a calm, premium experience where typography, spacing and hierarchy communicate far more than colour or decoration.

Visual consistency is achieved through repeated patterns rather than visual complexity.

---

# Colour Philosophy

Colour should guide attention rather than define the interface.

Large areas of the site should rely primarily on neutral surfaces, allowing accent colours to communicate interaction, status and emphasis.

The interface should never feel saturated or visually heavy.

Colour should answer one of three questions:

* What deserves attention?
* What state is this element in?
* What information is important?

If colour is not helping answer one of these questions, it should be reconsidered.

---

# Theme Strategy

## Main Site

The primary EllieAtWHL experience supports both Light Mode and Dark Mode.

Both themes are first-class experiences.

Neither theme should be treated as a simple inversion of the other.

Instead, each should feel intentionally designed while remaining unmistakably the same product.

Users switching between themes should recognise:

* identical hierarchy
* identical spacing
* identical typography
* identical interactions
* identical component structure

Only the visual presentation changes.

The overall experience should remain familiar.

---

## Spurs Women

The Spurs Women section currently presents a single theme.

This simplifies visual consistency while allowing greater focus on football content and data presentation.

Although theme switching is not currently supported, all other aspects of the EllieAtWHL design language remain applicable.

Future theme support should only be introduced if it can achieve parity with the quality of the main site's implementation.

---

# Surface Hierarchy

Rather than relying on many background colours, EllieAtWHL uses subtle differences in surface treatment to establish hierarchy.

Surfaces should generally fall into three categories:

## Primary Surface

The page background.

Large areas of calm space.

Minimal visual interruption.

---

## Secondary Surface

Cards.

Panels.

Navigation containers.

Grouped information.

These provide organisation without feeling visually heavy.

---

## Interactive Surface

Buttons.

Clickable cards.

Input controls.

Menus.

These should communicate interaction primarily through:

* contrast
* elevation
* hover behaviour
* focus treatment

rather than excessive colour.

---

# Contrast

Contrast should always prioritise readability.

Text should comfortably exceed minimum accessibility requirements.

Interactive controls should remain clearly visible regardless of theme.

Avoid creating contrast purely for visual drama.

---

# Typography Philosophy

Typography is the primary visual hierarchy tool throughout EllieAtWHL.

It should establish structure without requiring additional decoration.

The objective is that users can understand a page simply by scanning headings before reading body content.

---

# Typography Hierarchy

Every page should consistently follow a predictable hierarchy.

## Display

Used sparingly.

Reserved for major landing pages or hero sections.

Should immediately communicate page purpose.

---

## Heading Levels

Heading levels should always reflect document structure rather than visual preference.

Never skip heading levels purely because a different font size looks preferable.

Semantic HTML should remain the priority.

---

## Section Headings

Each major content block should begin with a clear heading.

Section headings should create natural stopping points while scanning.

---

## Body Copy

Body text should prioritise readability over density.

Comfortable line lengths are preferred.

Paragraphs should remain concise.

Long uninterrupted walls of text should be avoided.

---

## Supporting Text

Metadata.

Dates.

Captions.

Labels.

Descriptions.

These should remain visually secondary without becoming difficult to read.

---

# Text Alignment

Left alignment should be considered the default.

Centred text should be reserved for:

* hero sections
* empty states
* confirmation screens
* intentional visual emphasis

Avoid justified text.

---

# Spacing Philosophy

Spacing is one of the strongest characteristics of EllieAtWHL.

Whitespace should separate ideas rather than simply fill gaps.

Every margin and padding value should contribute towards creating a calm reading experience.

---

# Vertical Rhythm

Content should naturally breathe.

Sections should never feel compressed.

Large content blocks should have noticeably more separation than closely related components.

The distance between elements should communicate their relationship.

---

# Horizontal Rhythm

Content width should maximise readability.

Very long lines of text should be avoided.

Wide screens should use whitespace intentionally rather than stretching content indefinitely.

---

# Component Spacing

Every reusable component should maintain internal consistency.

Cards should have predictable padding.

Buttons should have consistent proportions.

Lists should follow established spacing patterns.

Components should appear as members of the same family.

---

# Corners

Rounded corners form an important part of the EllieAtWHL visual identity.

The objective is to create interfaces that feel approachable without appearing playful.

Corner radius should remain consistent across similar component types.

Avoid mixing many different corner radii within the same interface.

---

# Borders

Borders should be used sparingly.

Whenever possible, prefer spacing, contrast or subtle elevation to separate content.

When borders are required they should remain understated.

Borders should organise information rather than draw attention to themselves.

---

# Elevation

Elevation should communicate interaction rather than decoration.

Shadows should remain soft and restrained.

Hover states may increase elevation slightly, but dramatic movement should be avoided.

Users should sense interaction without becoming distracted by it.

---

# Icons

Icons should support recognition rather than replace text.

Where practical:

* labels should accompany icons
* icon styles should remain consistent
* decorative icons should be avoided

Icons should simplify interfaces rather than create visual clutter.

---

# Imagery

Photography should always support the surrounding content.

Images should feel authentic.

Avoid unnecessary stock imagery where practical.

Images should never dominate pages unless they are themselves the content.

For football-related content, imagery should complement statistics and editorial content rather than replacing them.

---

# Motion Philosophy

Animation exists to reinforce understanding.

Motion should communicate:

* state changes
* hierarchy
* continuity
* interaction

Animation should never exist purely because it is technically possible.

---

# Motion Principles

Transitions should feel smooth rather than dramatic.

Animations should generally be:

* subtle
* quick
* purposeful
* interruptible

Respect user preferences regarding reduced motion.

---

# Loading States

Loading should reassure users that progress is occurring.

Whenever practical:

* preserve layout
* minimise layout shift
* use skeleton loading rather than spinners
* avoid blank pages

Users should understand what is loading before it appears.

---

# Empty States

Empty states should never feel like errors.

Instead they should:

* explain why nothing is displayed
* suggest a next action where appropriate
* remain visually consistent with the rest of the interface

Every empty state should be treated as a designed experience rather than an afterthought.

---

# Visual Consistency Checklist

Every new page should feel visually compatible with the rest of EllieAtWHL.

Before implementation ask:

* Does this follow the established typography hierarchy?
* Is spacing consistent with existing pages?
* Are colours being used intentionally?
* Does this introduce unnecessary visual complexity?
* Would an existing component achieve the same goal?
* Does the interface feel calm?
* Is the content still the primary focus?
* Would this page look at home beside every other page on the site?

Consistency should always be considered a feature rather than a limitation.
